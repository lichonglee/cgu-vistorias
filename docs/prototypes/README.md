# Protótipos de produto

`painel-gerencial-demo.html` é uma simulação local de UX para o painel gerencial e o fluxo de chamados, versão 0.9.0. Os dados são fictícios; a alternância de perfis não implementa autenticação nem RBAC no servidor. O protótipo não faz parte do PWA, não integra com a API e não deve ser usado como sistema operacional.

O arquivo foi aprovado por Produto para inclusão como artefato candidato. O teste `tests/demo-carousel.test.cjs` fixa o SHA-256 revisado e cobre o ciclo do carrossel, os rascunhos por chamado e a segregação entre baixa operacional e homologação da chefia, sem dependências externas. Mudanças no protótipo exigem nova revisão e atualização consciente do hash.
